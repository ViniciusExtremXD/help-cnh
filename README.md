# Help Soluções e CNH

Landing page de defesa do motorista (React + Vite + Tailwind + Framer Motion).

```bash
npm install
npm run dev        # http://localhost:5174
npm run build
npm run deploy:gh  # build com base /help-cnh/ e publica na branch gh-pages
```

O número de WhatsApp fica em `src/config.ts` (`WHATSAPP_NUMBER`).
